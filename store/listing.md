# Chrome 웹스토어 등록 정보

## 확장프로그램 이름
Flow 자동화 도구 / Flow Automation Tool

## 짧은 설명 (132자 이내)
Google Flow AI 이미지/영상 생성을 자동화합니다. 프롬프트 대기열, 캐릭터 관리, 모델 선택, 자동 다운로드를 지원합니다.

## 상세 설명
Google Flow에서 AI 이미지와 영상을 대량으로 생성할 때 사용하는 생산성 도구입니다.

주요 기능:
• 프롬프트 대기열 — 여러 프롬프트를 한 번에 등록하고 순차 실행
• 캐릭터 시스템 — 프롬프트에 [캐릭터명]을 넣으면 해당 캐릭터 이미지를 ingredient로 자동 첨부
• 모델 선택 — Nano Banana 2 / Imagen 4 중 선택
• 출력 유형 — 이미지 또는 영상(Veo 3.1) 선택 가능
• 프로젝트별 스타일 — 프리픽스/서픽스로 일관된 스타일 적용
• 자동 다운로드 — 생성된 이미지/영상을 지정 폴더에 자동 저장
• Grok 영상 — Grok AI로 이미지→영상 변환 자동화
• 사이드 패널 UI — Flow 페이지 옆에서 편리하게 조작
• 폴더 스캔 — 로컬 폴더에서 캐릭터/장면 이미지를 일괄 불러오기

사용 방법:
1. Google Flow 페이지(labs.google/fx/flow)를 열어주세요
2. 확장프로그램 아이콘을 클릭하면 사이드 패널이 열립니다
3. 프롬프트를 입력하고 시작 버튼을 누르면 자동으로 이미지/영상이 생성됩니다

## 권한 사유 (Justification)

### activeTab
Flow 페이지 연결 상태를 확인하기 위해 현재 활성 탭의 URL을 읽습니다.

### tabs
사이드 패널에서 현재 탭 정보를 조회하여 Flow/Grok 페이지 여부를 판별합니다.

### scripting
사용자가 시작 버튼을 누르면 Flow 페이지에 자동화 스크립트를 주입하여 프롬프트 입력, 모델 선택, 생성 버튼 클릭, 이미지/영상 다운로드를 수행합니다.

### storage
사용자가 입력한 프롬프트, 프로젝트 설정, 캐릭터 데이터를 브라우저 로컬 저장소에 저장합니다.

### downloads
생성된 AI 이미지와 영상을 사용자가 지정한 폴더에 자동으로 다운로드합니다.

### sidePanel
Flow 페이지 옆에 사이드 패널 UI를 표시하여 사용자가 편리하게 확장프로그램을 조작할 수 있도록 합니다.

### unlimitedStorage
캐릭터 이미지를 Base64로 저장하므로 기본 5MB 저장 한도를 초과할 수 있습니다.

### host_permissions: https://labs.google/*
Google Flow 및 관련 페이지에서만 동작하며, 해당 페이지의 DOM에 자동화 스크립트를 주입합니다.

### host_permissions: https://grok.com/*
Grok AI 영상 자동화를 위해 Grok 페이지의 DOM에 스크립트를 주입합니다.

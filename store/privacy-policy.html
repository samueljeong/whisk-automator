개인정보처리방침

최종 업데이트: 2026년 2월 11일

1. 수집하는 정보

Flow 자동화 도구는 개인정보를 수집하지 않습니다.

확장프로그램이 저장하는 데이터는 다음과 같으며, 모두 사용자의 브라우저 로컬 저장소(chrome.storage.local)에만 저장됩니다:

  • 사용자가 입력한 프롬프트 텍스트
  • 프로젝트/캐릭터 설정
  • 자동 다운로드, 생성 간격 등 사용자 설정값

2. 데이터 전송

이 확장프로그램은 라이센스 키 검증을 위해 사용자가 입력한 라이센스 키만을 외부 서버(drama-s2ns.onrender.com)로 전송합니다. 라이센스 키 외에 개인정보나 사용 데이터는 일체 전송하지 않습니다.

라이센스 검증 결과는 브라우저 로컬 저장소에 캐싱되어 반복적인 서버 통신을 최소화합니다.

3. 웹사이트 접근

이 확장프로그램은 Google Whisk (labs.google) 페이지에서만 동작하며, 사용자가 입력한 프롬프트를 해당 페이지에 자동으로 입력하는 기능을 제공합니다.

4. 권한 사용 목적

  • activeTab / tabs: 현재 탭이 Whisk 페이지인지 확인
  • scripting: Whisk 페이지에 자동화 스크립트 주입
  • storage: 사용자 설정 로컬 저장
  • downloads: 생성된 이미지 자동 다운로드
  • sidePanel: 사이드 패널 UI 제공

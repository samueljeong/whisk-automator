📺 유튜브 메타데이터 — 위스크 자동화 v3.0
========================================

【제목】
AI 이미지 100장을 영상으로 자동 변환 | Whisk + Grok 자동화 도구 (무료 크롬 확장)

【설명】
Google Whisk으로 AI 이미지를 대량 생성하고, Grok으로 그 이미지를 영상까지 자동 변환하는 크롬 확장 프로그램을 소개합니다.

이번 v3.0 업데이트에서 Grok 영상 생성 기능이 추가되었습니다.
이미지 업로드 → 모션 프롬프트 입력 → 영상 생성 → 자동 다운로드까지
6단계 파이프라인이 완전 자동으로 돌아갑니다.

▶ 주요 기능
• Google Whisk AI 이미지 대량 자동 생성
• Grok 영상 자동 변환 (이미지 → 영상)
• 모션 프롬프트 자동 입력
• 생성된 영상 자동 다운로드
• 실시간 진행 상황 모니터링
• 팝업/오류 자동 처리

▶ 타임스탬프
00:00 인트로
(촬영 내용에 맞게 수정해주세요)

▶ 사용 방법
1. 크롬 확장 프로그램 설치 (개발자 모드)
2. 프롬프트 목록 입력 (줄바꿈으로 구분)
3. Start 버튼 클릭 → 자동 생성 시작
4. Grok 탭에서 이미지 → 영상 자동 변환
